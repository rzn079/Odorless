# Pre-AdSense Checklist

**Project:** Apartment Zero Waste Guide  
**Review Date:** [To be completed before submission]  
**Reviewer:** [Name]

## Content Verification

- [ ] All 40 articles contain 1000+ useful words (excluding headers, footers, FAQs)
- [ ] No duplicate or overlapping content between articles
- [ ] All articles answer real questions with practical information
- [ ] No invented statistics, studies, or sources
- [ ] No dangerous or misleading instructions
- [ ] Language is beginner-friendly and accessible
- [ ] No mentions of AI-generated content in articles
- [ ] Tutorials include warnings about variations in results
- [ ] No exaggerated promises or guarantees
- [ ] Professional tone maintained throughout

## Navigation & Structure

- [ ] Header navigation present and functional on all pages
- [ ] Footer navigation present and functional on all pages
- [ ] Breadcrumbs implemented correctly on all content pages
- [ ] Category pages list all relevant articles properly
- [ ] Internal links function and point to correct pages
- [ ] No broken links (404 errors) throughout site
- [ ] Search functionality returns relevant results
- [ ] Mobile menu opens/closes correctly
- [ ] Back-to-top button functions properly

## Institutional Pages

- [ ] About page explains portal purpose clearly
- [ ] About page identifies target audience (apartment dwellers, renters, beginners)
- [ ] Contact page has functional form with validation
- [ ] Contact page includes privacy notice
- [ ] Privacy Policy is comprehensive and specific
- [ ] Privacy Policy reflects actual technologies used
- [ ] Cookie Policy explains all cookie types in detail
- [ ] Terms of Use covers liability and intellectual property
- [ ] Author/Editorial Team page shows transparent information
- [ ] All institutional pages accessible from header or footer
- [ ] No fake addresses, phone numbers, or credentials

## Privacy & Consent

- [ ] Cookie banner appears on first visit
- [ ] Cookie banner allows accept and reject options
- [ ] Preferences can be changed later via settings
- [ ] Privacy Policy URL linked in cookie banner
- [ ] No non-essential cookies activated before consent
- [ ] Contact method for data requests provided
- [ ] User rights clearly explained
- [ ] Date of last policy update shown
- [ ] Third-party services disclosed (if any)

## Technical SEO

- [ ] Unique meta title on every page (no duplicates)
- [ ] Unique meta description on every page
- [ ] Canonical URLs set correctly on all pages
- [ ] H1 tag appears exactly once per page
- [ ] Heading hierarchy is logical (H1→H2→H3)
- [ ] robots.txt configured and accessible
- [ ] sitemap.xml includes all pages and articles
- [ ] RSS feed generated and valid
- [ ] No keyword stuffing in titles or content
- [ ] URLs are SEO-friendly (hyphens, no accents)

## Images

- [ ] All images have alt attributes
- [ ] Alt text is descriptive and contextual (not generic)
- [ ] Width and height attributes present on all images
- [ ] Images are responsive (max-width: 100%)
- [ ] File sizes optimized (<150KB for featured, <150KB for internal)
- [ ] No stock photo watermarks visible
- [ ] Featured images do NOT use lazy loading
- [ ] Internal images use loading="lazy"
- [ ] 120 total images created (40 articles × 3)
- [ ] Image filenames are descriptive (kebab-case)
- [ ] Images relate directly to nearby content

## Structured Data

- [ ] WebSite schema on homepage
- [ ] Organization schema present
- [ ] BreadcrumbList on all content pages
- [ ] Article/BlogPosting schema on each article
- [ ] Person schema for author information
- [ ] FAQPage schema only where FAQs are visible
- [ ] No fake reviews, ratings, or scores in schema
- [ ] Schema matches visible content exactly
- [ ] JSON-LD validates without errors
- [ ] Required fields present in all schemas

## Performance

- [ ] CSS is optimized (no unused rules)
- [ ] JavaScript is minimal and efficient
- [ ] Images use WebP format
- [ ] Lazy loading implemented for below-fold images
- [ ] No render-blocking resources in head
- [ ] Core Web Vitals scores checked (LCP, FID, CLS)
- [ ] CLS prevented with fixed image dimensions
- [ ] LCP optimized (main image not lazy-loaded)
- [ ] No unnecessary external libraries
- [ ] Fonts are system fonts or locally hosted
- [ ] Code is minification-ready

## Accessibility

- [ ] Skip to content link present and functional
- [ ] Keyboard navigation works throughout site
- [ ] Focus states are visible on all interactive elements
- [ ] Color contrast meets WCAG AA standards
- [ ] Form fields have associated labels
- [ ] ARIA labels used where needed
- [ ] Semantic HTML used throughout
- [ ] Screen reader friendly structure
- [ ] No content conveyed by color alone
- [ ] Touch targets are adequate size (44px minimum)

## Mobile & Desktop

- [ ] Mobile menu functions correctly
- [ ] Touch targets are adequate size
- [ ] Text is readable without zooming (16px base)
- [ ] No horizontal scrolling on mobile
- [ ] Desktop layout looks professional
- [ ] Responsive breakpoints work correctly
- [ ] Cross-browser compatible (Chrome, Firefox, Safari, Edge)
- [ ] Tablet layouts tested
- [ ] Large monitor layouts tested
- [ ] No functionality lost on smaller screens

## Ad Readiness

- [ ] Ad spaces reserved with HTML comments
- [ ] No ads placed near clickable elements
- [ ] Clear separation between content and ad spaces
- [ ] CLS prevention with fixed ad dimensions
- [ ] ads.txt file prepared with placeholder
- [ ] No policy-violating ad placements
- [ ] No encouragement of accidental clicks
- [ ] Ads not disguised as content
- [ ] No ads on institutional pages (recommended)
- [ ] Minimum heights defined for ad containers

## Links & Internal Architecture

- [ ] Each article has 4-8 internal links
- [ ] Anchor text is descriptive (not "click here")
- [ ] Links connect related topics logically
- [ ] Category pages link to all their articles
- [ ] Articles link back to category pages
- [ ] Homepage features all articles naturally
- [ ] Related articles section on each article
- [ ] Previous/next navigation in articles
- [ ] No orphaned pages (all reachable)
- [ ] No external affiliate links without disclosure

## Final Human Review

- [ ] Grammar and spelling checked on all pages
- [ ] No nonsensical or awkward sentences
- [ ] Tutorials are accurate and safe to follow
- [ ] Warnings about local variations included
- [ ] No exaggerated claims or guarantees
- [ ] Professional tone consistent throughout
- [ ] Brand consistency verified (colors, fonts, voice)
- [ ] No placeholder text remaining ([INSERT] items)
- [ ] Contact email is real or clearly marked as placeholder
- [ ] All dates are current and accurate

## Legal Compliance

- [ ] Privacy Policy complies with GDPR (if EU audience)
- [ ] Privacy Policy complies with CCPA (if California audience)
- [ ] Cookie consent meets local legal requirements
- [ ] Terms of Use limits liability appropriately
- [ ] Copyright notices present
- [ ] External links open appropriately (target="_blank" with rel="noopener")
- [ ] No copyrighted images used without permission
- [ ] No trademark violations in content
- [ ] Affiliate disclosures present if applicable
- [ ] Medical/safety disclaimers where needed

## Pre-Submission Validation

- [ ] Google Rich Results Test passed for structured data
- [ ] Google Mobile-Friendly Test passed
- [ ] PageSpeed Insights scores reviewed
- [ ] All official Google URLs verified as current
- [ ] Latest AdSense policies reviewed
- [ ] Site is fully crawled (no blocked resources)
- [ ] No "under construction" pages visible
- [ ] All 40 articles published and accessible
- [ ] Sitemap submitted to Search Console (when ready)
- [ ] Domain ownership verified in Search Console (when ready)
